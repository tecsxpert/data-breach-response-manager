# Data Breach Response Manager

The Data Breach Response Manager is an AI-powered web application designed to help organizations efficiently manage and respond to data breach incidents. The system enables users to create, track, and analyze breach records while leveraging an AI microservice to automatically generate descriptions, recommendations, and reports for better decision-making. The application follows a modern full-stack architecture where a React frontend communicates with a Spring Boot backend, which in turn interacts with a PostgreSQL database and an AI service built using Flask and the Groq API. The project uses technologies including Java 17, Spring Boot, PostgreSQL, Redis, Python Flask, React, Tailwind CSS, and Docker to ensure scalability, performance, and ease of deployment. The folder structure is organized into backend, ai-service, and frontend modules along with a docker-compose configuration for running the entire system with a single command. To run the project, ensure prerequisites such as Java 17, Node.js, Docker, and Git are installed, then clone the repository, create a .env file with required environment variables like database credentials, JWT secret, and Groq API key, and execute docker-compose up --build. Once running, the frontend is accessible at http://localhost, the backend at http://localhost:8080, and the AI service at http://localhost:5000. Key features of the system include secure JWT-based authentication, full CRUD operations for breach records, AI-generated insights, and a fully containerized deployment setup, making it suitable for real-world security incident management and demonstration purposes.
